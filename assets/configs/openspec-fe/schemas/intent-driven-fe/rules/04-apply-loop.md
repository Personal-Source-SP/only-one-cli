# Apply Loop Rules

- Process phases in dependency order. Do not begin next phase before explicit acceptance.
- Execute only declared tasks and scope.
- Tick `[x]` only after required implementation, evidence, acceptance, and verification succeed.
- On feedback, reopen only affected tasks to `[ ]`, rework, rerun verification, and request acceptance again.
- Preserve unrelated working-tree changes. Do not stage or commit workflow changes.
