# UI and UX Development

- MUST ensure responsive behavior on mobile, tablet, and desktop.
- MUST use semantic HTML. AVOID overusing `div`.
- SHOULD keep user flows minimal, clear, and low-friction.
- SHOULD use established UX patterns when they fit user goals and existing product conventions.
- MUST preserve accessibility, including keyboard operation, visible focus, labels, and suitable semantic landmarks.
- MUST use TailwindCSS when project uses TailwindCSS. AVOID plain CSS unless necessary or required by existing project patterns.
